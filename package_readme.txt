GasketFit Beta — PFDMR

ENGLISH

Start GasketFit.exe. No Python installation is required.
Keep the supplied folders beside the application.

Portable: settings are saved beside the EXE.
Installed: settings are saved in your Windows user profile.
English, German and French are included. Choose your language in Settings.

This is a beta version. Back up your projects and check exported models
in your slicer before printing.

Downloads and documentation: https://github.com/urscaviezel/GasketFit
Report problems: https://github.com/urscaviezel/GasketFit/issues

source contains the application source code for inspection and rebuilding.

DEUTSCH

GasketFit.exe starten. Eine Python-Installation ist nicht erforderlich.
Die mitgelieferten Ordner neben der Anwendung belassen.

Portabel: Einstellungen werden neben der EXE gespeichert.
Installiert: Einstellungen werden im Windows-Benutzerprofil gespeichert.
Englisch, Deutsch und Französisch sind enthalten. Sprache unter Einstellungen wählen.

Dies ist eine Beta-Version. Projekte sichern und exportierte Modelle vor
dem Druck im Slicer kontrollieren.

Downloads und Dokumentation: https://github.com/urscaviezel/GasketFit
Probleme melden: https://github.com/urscaviezel/GasketFit/issues

LICENSE, THIRD_PARTY_NOTICES.txt und licenses enthalten die Lizenzinformationen.
source enthält den Quellcode der Anwendung zum Nachlesen und erneuten Bauen.
